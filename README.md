A program that writes one one-line joke about working beside AI coding agents to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

## The joke

> My AI coding agent writes the code, reviews its own pull request, approves it in seconds — and I'm still the one explaining the bug at standup.
